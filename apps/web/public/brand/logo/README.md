# 图叙 Logo 资源

这里集中存放产品 Logo。SVG 是源文件，PNG 是由 SVG 导出的透明位图。

| 文件 | 用途 |
| --- | --- |
| `logo-mark.svg` | 图形 Logo，适合导航、App 图标和 favicon |
| `logo.svg` | 竖版完整 Logo，包含“图叙 / StoryFrame”字标 |
| `logo-horizontal.svg` | 横版完整 Logo，适合页头和品牌展示 |
| `logo-mark.png` | 图形 Logo 的透明 PNG |
| `logo.png` | 竖版完整 Logo 的透明 PNG |
| `logo-horizontal.png` | 横版完整 Logo 的透明 PNG |

应用代码引用稳定文件名；以后更换 Logo 时，保留对应文件名即可直接替换。优先替换 SVG，PNG 用于下载、品牌手册或不便使用 SVG 的场景。
