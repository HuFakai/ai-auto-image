# 阶段 2：漫画与高级视觉

> 文档定位：原始阶段范围与验收基线。实现已发生演进，本文不作为当前待办清单；当前执行以 [当前状态](../current-status.md) 和 [当前路线图](../current-roadmap.md) 为准。

## 1. 阶段目标

在阶段 1 的稳定图文能力上增加科普漫画、角色连续性、场景连续性、商品高级合成和局部视觉返修，使系统能够处理比普通图卡更复杂的视觉叙事。

## 2. 范围

### 包含

- 科普漫画 Recipe。
- 角色、服装和场景 Bible。
- 漫画分镜与页面布局。
- 角色参考图和上一页连续性。
- 对话气泡、旁白和拟声词渲染。
- 参考图预算、压缩和选择。
- 商品抠图、换背景和多场景变体。
- 局部重绘和区域替换。
- 视觉一致性和连续性检查。

### 不包含

- 长篇动画视频。
- 自动训练 LoRA。
- 全自动正式发布。
- 开放式工作流画布。

## 3. 新增领域模型

### Character Bible

- 姓名、角色 ID 和别名。
- 年龄段、体型、脸型、发型和显著特征。
- 固定色板。
- 默认服装和服装集合。
- 表情参考。
- 正面、侧面、背面和三分之四视图。
- 禁止变化项。
- 参考资产列表。

### Scene Bible

- 场景名称和 ID。
- 时间、天气和光照。
- 固定空间关系。
- 关键物品及位置。
- 色板和材质。
- 建立镜头和参考图。

### Comic Storyboard

- 页面和面板数量。
- 阅读顺序。
- 每格景别、机位和构图。
- 出场角色、动作和表情。
- 对白、旁白、拟声词。
- 场景连续性要求。
- 参考图绑定。

## 4. 漫画生产流程

```text
主题/科普资料
  → 事实与教学目标
  → 故事化改写
  → 角色与场景 Bible
  → 页面/面板 Storyboard
  → 低成本布局草图
  → 用户或自动确认
  → 角色参考图
  → 分页生成
  → 文字和气泡合成
  → 连续性检查
  → 局部返修
  → 导出
```

## 5. 连续性策略

### 身份连续性

- 每个角色建立规范描述和参考图。
- 每个 Panel Prompt 引用相同角色字段。
- 支持图像模型的 Provider 使用参考图编辑。
- 不支持参考图的 Provider 降级为固定描述、稳定 Seed 和减少镜头变化。

### 服装连续性

- Storyboard 显式声明当前服装 ID。
- 服装变化必须由剧情事件触发。
- 视觉审查对比颜色、款式和显著配件。

### 场景连续性

- 场景建立镜头作为锚点。
- 记录角色和物品的空间位置。
- 下一格 Prompt 注入上一格必要状态，而不是注入全部历史。

### 长程记忆

- 最近 1–2 页使用图片引用。
- 更早内容压缩为结构化连续性摘要。
- 超过 Provider 参考图预算时按角色、场景和前一页优先级选择。

## 6. 参考图管理

每张参考图记录：

- 角色、场景或布局用途。
- 来源和授权状态。
- 分辨率、比例和文件大小。
- 视觉特征向量或描述。
- 适用范围。
- 是否允许发送到第三方 Provider。

发送前处理：

- EXIF 方向修正。
- 长边压缩。
- 格式统一。
- 去除不必要元数据。
- 根据 Provider 限制控制数量和体积。

## 7. 漫画文字渲染

漫画同样遵循双模式。默认允许主力图片模型直接生成中文对白、旁白和拟声词；用户可以针对整个项目、页面或单格开启确定性文字渲染兜底。

原生模式需要检查对白归属、错字、额外文字和阅读顺序。确定性模式要求模型输出人物和场景时保留气泡安全区。

Render Engine 新增：

- 椭圆对白气泡。
- 锯齿喊叫气泡。
- 云状思考气泡。
- 矩形旁白框。
- 拟声词路径文字。
- 自动避让人物面部和画面主体。
- 中文竖排和横排。

确定性模式下气泡布局失败时，先调整气泡和字号；只有安全区不足才重新生成图片。

## 8. 高级产品视觉

### 商品抠图

- 支持透明背景资产。
- 边缘检查和阴影补偿。
- 保留商品 Logo 和包装文字，不让模型重绘。

### 场景换图

- 需要严格保留商品包装时，AI 只生成背景或以商品参考图编辑；原生文字模式也可以生成完整营销图，但必须检查包装、Logo、价格和参数。
- 商品主体尺寸、角度和包装保持一致。
- 生成生活方式、棚拍、电商主图和节日场景变体。

### 局部返修

- 用户框选区域。
- 记录 Mask、Prompt 和父资产。
- Provider 支持 Mask 时使用原生编辑。
- 不支持 Mask 时使用裁剪、编辑、边缘融合的降级流程。

## 9. 视觉质量检查

### 规则检查

- 页面和面板数量正确。
- 气泡不越界、不遮挡面部。
- 人物名称与对白归属正确。
- 画布方向和比例一致。
- 商品包装和关键参数没有被错误覆盖。

### 多模态检查

- 角色脸型、发型、服装和配色是否漂移。
- 同一场景中的主要物品是否消失或移动异常。
- 动作是否符合 Storyboard。
- 是否出现额外人物、额外肢体和意外文字。
- 科普图是否与事实陈述矛盾。

检查结果输出到 `QualityReport`，支持针对单页、单格或单个资产创建返修任务。

## 10. Provider 能力路由

系统根据任务要求选择 Provider：

| 能力 | 使用场景 |
|---|---|
| 文生图 | 独立场景、背景、风格探索 |
| 单参考图编辑 | 角色或商品一致性 |
| 多参考图编辑 | 多角色、角色+场景、角色+布局 |
| Mask 编辑 | 局部返修 |
| 高分辨率 | 最终封面和产品主视觉 |

如果当前 Provider 不满足 Recipe 的最低能力，创建任务前提示用户切换 Provider 或接受降级结果。

## 11. 测试计划

### 固定漫画评测集

- 单角色四格科普漫画。
- 双角色对话。
- 同一角色跨三页。
- 昼夜场景切换。
- 服装变化事件。
- 包含数字、公式或专业术语的科普内容。

### 一致性指标

- 角色显著特征保持率。
- 服装 ID 正确率。
- 对白归属正确率。
- 页面方向和比例正确率。
- 返修后非目标区域保持率。

### 人工评审

- 人物是否容易辨认。
- 阅读顺序是否明确。
- 科普表达是否准确。
- 文字在手机端是否清晰。
- 单页返修是否破坏全套风格。

## 12. 交付物

- 科普漫画 Recipe。
- Character Bible 和 Scene Bible 编辑器。
- 漫画 Storyboard 编辑器。
- 漫画页面模板和气泡组件。
- 参考图管理。
- 局部返修工具。
- 多模态质量检查。
- 高级商品场景生成功能。

## 13. 验收标准

- 可以从一个科普主题生成至少 3 页连续漫画。
- 默认支持模型原生中文对白；开启确定性模式后，对白和旁白可独立编辑并由程序渲染。
- 同一角色的关键特征在连续页面中保持可辨认。
- 任意单格可以重新生成而不影响其他格。
- 商品包装和价格信息不由图片模型重绘。
- 参考图数量、大小和发送范围受到能力表与隐私策略控制。

## 14. 退出条件

至少 10 套多页漫画和 10 套商品高级视觉通过人工评审，角色/场景连续性问题可以被检测并局部返修后，进入阶段 3。
