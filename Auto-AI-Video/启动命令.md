# 启动命令

## macOS / Linux（使用 uv）

> 需要已安装 uv，且已在项目根目录执行过 `uv sync`。

```bash
# 终端 1：FastAPI
uv run python api/app.py --host 127.0.0.1 --port 18123

# 启动前只读检查（项目根目录执行）
uv run python scripts/run_production.py status

# 终端 2：Next.js Production Desk
cd studio
npm run dev
```

## Windows（使用 pip + venv）

> 本机使用 pip + venv（不带 uv），Python 路径为项目内的 `.venv-windows\Scripts\python.exe`。
> 所有命令都在项目根目录下执行；项目文件夹名称可以是任意名称。

### 终端 1：API 后端（必需）

```powershell
.\.venv-windows\Scripts\python.exe api\app.py --host 127.0.0.1 --port 18123
```

### 终端 2：网页控制台（必需）

```powershell
cd studio
$env:PORT=13123
$env:PIXELLE_API_URL="http://127.0.0.1:18123"
npm run dev
```

浏览器访问 `http://127.0.0.1:13123`。

### 持续生产 Runner（可能产生 API 费用）

启动前只读检查：

```powershell
.\.venv-windows\Scripts\python.exe scripts\run_production.py status
```

启动 API 和网页控制台后，使用控制台顶部的“持续生产”开关。Runner 由 API 托管，不再需要单独终端。

### 日常起手建议

也可以直接双击根目录的 `Windows一键启动.bat`，它会自动完成环境检查并启动 API 与网页控制台。停止时双击 `Windows一键关闭.bat`。
