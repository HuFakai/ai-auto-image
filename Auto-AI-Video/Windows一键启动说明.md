# Windows 一键启动说明（小白版）

适用系统：64 位 Windows 10 / Windows 11。第一次运行需要联网，建议至少预留 8 GB 磁盘空间。

## 最简单的使用方法

1. 把整个项目文件夹解压到电脑本地，例如 `D:\Auto-AI-Video`。文件夹名称可以任意取名，不要只复制启动脚本。
2. 双击 `Windows一键启动.bat`。
3. 如果 Windows 弹出安装或权限确认窗口，确认发布者可信后点击“是”。
4. 第一次运行通常需要 10～30 分钟。窗口没有报错时不要关闭。
5. 准备完成后，浏览器会自动打开 `http://127.0.0.1:13123`（端口被占用时以脚本最后输出的地址为准）。
6. 打开右上角“模型与系统设置”，填写自己的 API 地址、API Key 和模型。

以后再次使用时，仍然双击同一个文件。已经安装好的环境和依赖会自动复用，启动会快很多。

启动过程完全自动，不会要求按回车确认。脚本会关闭当前控制台的“快速编辑暂停”功能，鼠标误点窗口也不会再让安装过程停住。API 和 Studio 会以隐藏后台进程运行，不依赖额外的 PowerShell 控制台；这对 UU 云电脑等限制子窗口的环境也适用。

## 脚本会自动完成什么

- 检测 Python 3.11+；没有时安装 Python 3.12。
- 检测 Node.js 22+；没有时安装 Node.js LTS。
- 检测 FFmpeg / FFprobe；没有时自动安装（国内加速镜像优先，自动重试）。
- 在项目目录创建独立的 `.venv-windows` Python 虚拟环境，不污染电脑上的其他 Python 项目。
- 安装 Python、网页控制台和 HyperFrames 渲染器依赖。
- 安装项目截图/渲染所需的 Chromium 浏览器。
- 缺少配置时，从示例安全创建 `config.yaml` 和 `studio/.env.local`；已有配置永远不会被覆盖。
- 分别启动 API 和网页控制台，并在服务就绪后打开浏览器。

## 国内镜像、测速选源与失败重试

脚本在安装依赖前会先给各个镜像"测网速"（每个镜像下载约 1.5 MB 的真实文件样本），并实时显示每个源的速度，然后自动优先使用最快的源：

- Python 依赖候选源：清华、阿里云、腾讯云、中科大、华为云、PyPI 官方。
- npm 依赖候选源：npmmirror、腾讯云、华为云、npm 官方。
- FFmpeg 的 GitHub 加速代理也会先测速，最快的代理优先使用。

下载大文件（如 FFmpeg、Node.js 安装包）时会显示实时速度。如果当前源的平均速度持续低于 256 KB/s，脚本会主动放弃该源并自动切换到下一个，不会一直卡在慢速源上等待。某一个镜像临时不可用时也不需要手工改配置，脚本会自动换下一个。

FFmpeg 会优先通过 GitHub 加速代理（ghfast.top、gh-proxy.com、ghproxy.net、github.moeyy.xyz、gh.ddlc.top）下载 BtbN 或 gyan 官方构建的便携版，然后依次回退到 gyan.dev 官方站和 GitHub 直连，只有全部失败时才尝试 winget。每个下载源都会自动重试，下载时会显示实时进度；下载完成后先校验压缩包内确实包含 `ffmpeg.exe` 和 `ffprobe.exe`，再实际运行一次确认没有被杀毒软件拦截。某个加速代理临时失效时脚本会自动换下一个，不需要手工配置。

镜像只对本次项目安装生效，不会偷偷修改电脑的全局 pip 或 npm 配置。通过镜像下载的 Python 安装程序会验证微软 Authenticode 签名；便携 Node.js 压缩包会用 Node.js 官方 SHA-256 清单校验。

## 如何开关“持续生产 Runner”

无需再单独启动 Runner。打开网页控制台，使用顶部的“持续生产”开关即可启动或停止。开关状态保存在当前项目的 `data` 目录；下次启动 API 时，如果上次保持开启，Runner 会自动恢复。

项目中的栏目可能处于启用状态。开启 Runner 可能立即调用文字、图片和视频模型并产生费用；请先确认 API Key、模型和栏目配置无误。

## 如何停止

启动后不会再额外弹出 API/Studio 的 PowerShell 窗口。服务日志位于项目目录的 `.windows-tools`：

- `api-stdout.log` / `api-stderr.log`
- `studio-stdout.log` / `studio-stderr.log`

需要停止时，双击项目根目录的 `Windows一键关闭.bat`。脚本会只识别当前项目路径下的 API、Studio、Runner 和 HyperFrames 进程，项目文件夹可以任意改名。

## 常见问题

### 某个镜像下载失败

先等待，脚本会自动尝试其他镜像。如果最后仍失败，检查网络、代理、防火墙和剩余磁盘空间，然后重新双击。已经完成的步骤会被复用。

### Windows 提示找不到 winget

脚本对 Python 和 Node.js 准备了便携/官方回退方案；FFmpeg 优先走国内可达的加速镜像下载便携版，winget 只是最后兜底。如果企业电脑拦截了所有下载，请让管理员安装“应用安装程序（App Installer）”，或手工安装 Python 3.12、Node.js 22+ 和 FFmpeg 后重试。

### PowerShell 提示脚本被禁止运行

必须从 `Windows一键启动.bat` 进入，不要直接双击 `.ps1` 文件。批处理文件只为这一次启动临时放行脚本，不会修改系统的永久执行策略。

### 页面打不开

先查看项目根目录的 `windows-startup.log`，再查看 `.windows-tools` 中对应服务的 `*-stderr.log`。脚本默认使用 API `18123`、Studio `13123`；如果端口被占用，会自动从后续端口选择空闲端口。也可以在启动前设置 `PIXELLE_API_PORT` 或 `PIXELLE_STUDIO_PORT` 指定首选端口。

如果在 UU 云电脑上看到 `Unknown error (0xffffffff)`，通常是云桌面限制创建 PowerShell 子窗口。新版启动器已经改为通过 .NET 直接启动隐藏的 `cmd.exe` 服务包装进程，不需要手工打开 PowerShell；请确认项目完整解压后重新双击 `Windows一键启动.bat`。

### 窗口标题前出现“选择”并停止运行

这是旧版脚本遇到 Windows 控制台“快速编辑”暂停，不是等待输入。新版脚本已经自动关闭该模式。请先按 `Esc` 退出当前选中状态并关闭旧窗口，更新项目后重新双击启动文件；新版全过程不需要按回车。

### 想强制重新安装全部依赖

在命令提示符执行（把路径替换为你实际的项目目录）：

```bat
"你的项目目录\Windows一键启动.bat" -ForceInstall
```

这不会删除 `config.yaml`、数据库、作品或 API Key。
