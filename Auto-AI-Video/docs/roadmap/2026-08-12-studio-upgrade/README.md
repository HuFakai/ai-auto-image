## 已确定的产品范围

保留并加强：

- Grok 文本、图片、视频直连能力；
- 标准短视频、图生视频、素材驱动视频；
- Edge TTS、HTML 模板、FFmpeg 合成；
- 持久化任务、Grok request_id 恢复、幂等重试；
- 频道、库存水位、持续补产、成片库；
- 审核门禁、人工发布标记和 AI 制片决策辅助。

明确移除：

- ComfyUI、RunningHub、ComfyKit 及全部工作流 JSON；
- 数字人口播；
- 动作迁移；
- 仅服务于上述能力的 UI、配置、文档、依赖和兼容字段。

第二批候选精简项需独立评审，不与第一批混删：

- 未被代码引用的 `fastmcp`；
- 仅被动作迁移使用的 `moviepy`；
- 示例性质的 `CustomPipeline`；
- Grok-only 运行模式下不再需要的 DashScope、Kling、Seedance、Seedream 等媒体供应商。

其中其他媒体供应商建议先做成可选 extra，再决定是否彻底删除，避免一次改动过大。

## 核心决策

- 后端继续使用 FastAPI，不重写已经稳定的生成内核。
- Next.js Studio 已完成替换并成为唯一前端入口。
- 新前端定位为“短视频生产控制台”，而不是传统时间线剪辑器。
- 第一阶段优先解决批量生产的可见性、可控性和审核效率，不先做复杂逐帧编辑。
- 排期、平台自动发布和数据反馈按产品决策暂不实施；现有人工发布标记只服务库存补货。
