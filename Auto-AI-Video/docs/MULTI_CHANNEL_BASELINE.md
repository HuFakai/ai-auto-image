# 多频道持续生产基线

更新时间：2026-08-19

## 已封闭范围

- 频道配置统一由 `production/channels/*.yaml` 热加载；
- 每个频道都有独立的选题、库存、并发、分镜、内容门禁和质量修复策略；
- 中国古诗词与少儿寓言使用 `api/default/video`，任务创建时冻结设置页当时选中的具体视频模型；
- 既有早安、科普和心理学频道继续保留固定工作流，避免无意改变历史行为；
- 少儿寓言默认停用，完成测试样片审核后再启用；
- 配置加载、唯一频道 ID、默认启停状态和关键策略由自动化测试覆盖。

## 当前运行状态

配置和 `/v1/models` 目录读取正常，但 2026-08-19 的隔离视频创建测试返回：

```text
503 upstream_model_unavailable: 当前 Client Key 限定范围不支持已配置的视频模型
```

历史失败主要是上游账号池 `429 upstream_quota_exhausted`。这不是本地频道配置、SQLite、FFmpeg 或任务恢复损坏。生产账本中的频道当前保持人工暂停，禁止在上游权限恢复前执行 `run_production.py once` 或解除暂停，以免继续累积失败任务。

## 恢复生产门槛

1. 设置页 `/models` 连接测试成功；
2. 使用“测试样片”或隔离的单镜视频测试确认创建接口不再返回 429/503；
3. 先只恢复一个低并发频道，观察一个完整视频成功入库；
4. 核对 Grok request ID、本地视频、Revision 和质量报告均已持久化；
5. 再逐个恢复其他频道，避免账号池瞬时并发过高。

历史失败记录保留用于诊断与审计，不在基线提交中清空。
